This section is the lookup layer: exact commands, flags, environment variables and Go APIs. Reach for a [how-to guide](/amarra-cais/docs/how-to/) when you want a walkthrough; come here when you need the precise name or option.

## Pages

- [CLI](/amarra-cais/docs/reference/cli/) — every `amarra-cais` command and alias, plus the framework `make` targets.
- [Generators](/amarra-cais/docs/reference/generators/) — `amarra-cais g …`, resource options, field types, and what `destroy` undoes.
- [Router](/amarra-cais/docs/reference/router/) — `cais.Router`: HTTP methods, groups, path params and designed 404s.
- [Views and kit](/amarra-cais/docs/reference/views-and-kit/) — `view.Write` and the shipped `<.input>` / `<.table>` components.
- [Amarra JS](/amarra-cais/docs/reference/amarra-js/) — Drive, Frame, Stream and the `amarra-hook` attributes.
- [Template helpers](/amarra-cais/docs/reference/template-helpers/) — `linkTo`, `dict`, `csrfField`, `fieldError` and friends.
- [Configuration](/amarra-cais/docs/reference/configuration/) — environment variables, `cais.Load()`, validation and cookies.
- [Middleware](/amarra-cais/docs/reference/middleware/) — recover, security headers, CSRF, sessions, flash, auth and rate limits.
- [Jobs API](/amarra-cais/docs/reference/jobs-api/) — enqueue, inspect and recover SQLite background jobs.

For the reasoning behind these APIs, see [Explanation](/amarra-cais/docs/explanation/). New here? Start at [Getting started](/amarra-cais/docs/getting-started/).
