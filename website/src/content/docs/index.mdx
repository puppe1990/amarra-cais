<CardGrid>
  <Card title="HTML first, no SPA" icon="pencil">
    Handlers call `view.Write`; Drive morphs `#amarra-main` on navigation. No Vite, no Svelte, no
    Inertia.
  </Card>
  <Card title="Rails-style CLI" icon="rocket">
    `amarra-cais new`, `g resource`, `g auth`, `g job`, `g stream chat` — and `destroy` to undo
    generator output.
  </Card>
  <Card title="Kit + hooks" icon="puzzle">
    `<.table>`, `<.form>`, `<.stat>` and `amarra-hook` builtins like `dialog`, `dropdown`, `bulk`,
    `nav` and `theme`.
  </Card>
  <Card title="One SQLite file" icon="database">
    WAL, busy timeout and a background job queue in the same file — plus PWA and mobile testing
    built in.
  </Card>
</CardGrid>
